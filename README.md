# l151820/homebrew-tap

Homebrew-Tap für [MacIPMI](https://github.com/l151820/MacIPMI) – IPMI-Verwaltung und KVM-Konsole für Supermicro-X9-Server.

```bash
brew install --cask l151820/tap/macipmi
```

Installiert `MacIPMI.app` nach `/Applications` und `ipmi-cli` in den PATH. Der Cask wird bei jedem Release von MacIPMI automatisch aktualisiert.
